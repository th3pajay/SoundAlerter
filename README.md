SoundAlerter provides instant, critical voice alerts for enemy and friendly spell usage. This release significantly overhauls the addon for better reliability, easier maintenance, and expanded spell coverage on WoW Ascension: Bronzebeard.

Never miss a "Cyclone", "Divine Shield", or "Shadowmeld" again!

✨ Key Updates
Expanded Spell Content: Added many new abilities (Artifacts, Legendaries, and class spells) with voice-cloned audio.

Ascension Integration: Spell IDs are piggybacked on the Ascension database (using the "Show Ids In tooltips" feature) for expanded, though preliminary, alerts.

Modernized Structure: Spells are consolidated by Class/Name and now auto-support standard and private server ID formats (e.g., [SpellID] and 11[SpellID]).

Full Options Support: All new spells are integrated with in-game toggle options (/sa).

Note: As this is an early release for this server, spell IDs are not fully confirmed. Expect potential errors.

🛡️ Core Features
Voice Alerts: Real-time audio alerts for major CC, interrupts, and cooldowns.

Customization: Toggle alerts on/off via the in-game options menu (/sa).

Localization: Includes English and Spanish voice packs.

Reliable: Hooks directly into the WoW Combat Log.

🚀 Usage & Setup
1. Installation
Download the latest release ZIP and extract the entire SoundAlerter folder into your WoW AddOns directory (e.g., .../Interface/AddOns/).

2. In-Game Configuration
Log in and open options with /sa.

New alerts are enabled by default. Customize toggles as needed.
