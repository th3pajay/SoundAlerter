SoundAlerter: Enhanced and "vibe-code" updated for WoW Ascension: Bronzebeard (20251014)
This release overhauls the addon for better reliability, easier maintenance, and expanded spell coverage. 

Based on the "Interface / Help / Show Ids In tooltips" and based on the Ascension db piggybacked most of the spells and added new ones to the addon alerts and to options to manage them, with voice cloned audio.
As at the moment ot early release of this addon none of the spell ID's are fully confirmed, please expect errors and mistakes made.

---
✨ Key Updates
New Spell Content: Added many new class abilities, Artifact, and Legendary spells across all classes, complete with voice-cloned audio.

Modernized Structure: Spells in spellist.lua are now logically organized by Class and Spell Name, with all ranks consolidated for simpler configuration.

Enhanced Reliability: Corrected numerous existing spell IDs and added automatic compatibility for both standard and private server spell ID formats (e.g., [SpellID] and 11[SpellID]).

Full Integration: All new spells are integrated with corresponding toggle buttons in the in-game options menu (/sa).

📝 Usage
Open options with /sa.

New alerts are enabled by default.
